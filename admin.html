Integração ERP & API

🔐 Ligação segura ao ERP

No KanawaSoft, abra Integrações API e gere uma chave para a empresa D.PEDRO SOLUÇÕES com as permissões catalog:read e orders:write. Cole aqui o endpoint e a chave. O servidor valida a empresa remota, guarda o segredo no Supabase Vault e limpa o campo do navegador. Nunca use uma chave de service_role.
